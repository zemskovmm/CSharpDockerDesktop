# ENG-0001.rule-desktop-stack

## Rule

Implement CSharpDockerDesktop in C# on .NET 10. Use Uno Platform Skia Desktop for the desktop UI and the Uno Skia Win32 shell for Windows. The desktop application target is net10.0-desktop.

Use Skia's Vulkan backend on Windows when available, with automatic OpenGL and then software fallback. On macOS, use Uno's AppKit host with Metal when available and software fallback. Keep rendering backend selection within Uno's supported host configuration.

## Applicability

Always

## Rationale

These are explicit current choices in the supplied MVP technology decision table and desktop build-target section. A different language, runtime, or UI framework would be a new Engineering decision even if it preserved the product behavior.

The accepted rendering decision combines Uno's shared controls and layout with GPU acceleration through Skia. Vulkan is preferred where the delivered Windows host supports it; macOS uses the supported Metal backend. Automatic fallback preserves access on machines without a usable GPU backend.

## Guidance

Apply the desktop target to the application host; do not infer that non-UI libraries must use a desktop-specific target. Windows and macOS delivery retain the shared UI and resource workflows required by IDD-0001 and IDD-0003.

Configure the production and graphical verification hosts consistently. Let Uno and Skia own graphics initialization and fallback; do not require a Vulkan-only startup or a custom Vulkan renderer. macOS does not require Vulkan or a Vulkan-to-Metal translation layer. This decision does not add Linux to the delivery scope.

This rule does not select a package version, installer type, update channel, NativeAOT, or a trimming policy from surrounding recommendations.

## Verification

Project/runtime declarations and the desktop host establish C#, .NET 10, Uno Skia Desktop, net10.0-desktop, and the Windows Win32 shell. The delivered Windows application operates through that selected stack.

Host configuration and runtime evidence distinguish requested and actually selected rendering backends. Windows evidence covers Vulkan-capable and fallback systems; macOS evidence covers the AppKit/Metal path. A successful cross-platform build alone does not establish Windows Vulkan or fallback runtime behavior.
