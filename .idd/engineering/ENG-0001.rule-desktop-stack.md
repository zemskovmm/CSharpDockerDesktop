# ENG-0001.rule-desktop-stack

## Rule

Implement CSharpDockerDesktop in C# on .NET 10. Use Uno Platform Skia Desktop for the desktop UI and the Uno Skia Win32 shell for Windows. The desktop application target is net10.0-desktop.

## Applicability

Always

## Rationale

These are explicit current choices in the supplied MVP technology decision table and desktop build-target section. A different language, runtime, or UI framework would be a new Engineering decision even if it preserved the product behavior.

## Guidance

Apply the desktop target to the application host; do not infer that non-UI libraries must use a desktop-specific target. Keep future macOS delivery distinct from required current Windows behavior.

This rule does not select a package version, installer type, update channel, NativeAOT, or a trimming policy from surrounding recommendations.

## Verification

Project/runtime declarations and the desktop host establish C#, .NET 10, Uno Skia Desktop, net10.0-desktop, and the Windows Win32 shell. The delivered Windows application operates through that selected stack.
