# IDD-0003.spec-shared-resource-ui

## Intent

Provide consistent resource navigation, search, inspection, error presentation, and keyboard access across the client.

## Related Specifications

IDD-0002, IDD-0004, IDD-0005, IDD-0007, IDD-0009, IDD-0010, IDD-0011.

## Behavior

- Resource navigation opens tables and the selected resource's details.
- Tables support responsive search/filtering over the relevant loaded resource metadata. Resource identity can be displayed in shortened form while its full value remains available to copy.
- Inspect displays the actual Docker JSON with readable formatting, search, expandable/collapsible structure, and copy actions for paths and values.
- Preserve actual Inspect content. Any heuristic redaction in an Overview does not redefine the raw Inspect response.
- Destructive actions open an explicit confirmation before the request is sent. Pending work and per-operation errors remain visible.
- State is communicated with text or another non-color cue as well as any color indicator.
- Keyboard access covers resource search, refresh, opening the selected resource, opening delete confirmation, and search within Logs/Inspect.
- Settings and presentation preferences may be retained; resource snapshots and stream history are governed by IDD-0006, IDD-0007, and IDD-0009.

## Product-Significant Architecture And Constraints

Resource tables and logs must use virtualization and maintain responsiveness during Docker I/O, searching, filtering, and large updates. Copying or exporting sensitive content is a deliberate user action under IDD-0010.

The source's concrete shortcut bindings are a proposal rather than an accepted binding contract. The required keyboard actions above are current intent; exact keys and additional convenience shortcuts need confirmation.

## Non-goals

- A common artificial backend pagination protocol across Docker resource types.
- A Compose-oriented navigation model.
- Silently transmitting Inspect content as part of copy, diagnostics, or telemetry.

## Acceptance Criteria

- The user can find a resource, open its details, inspect/search its JSON, and copy a value without blocking the interface.
- Keyboard interaction reaches the required actions and preserves confirmation before destructive requests.
- A resource state is understandable without relying on color alone.
- Inspect retains the daemon's actual data while making sensitive copying explicit.

## Verification

Interaction evidence covers keyboard navigation, confirmation cancellation, large virtualized tables, Inspect search/copy, absent fields, error presentation, and state recognition without color. Verification assesses behavior rather than mandating private controls or view-model structure.
