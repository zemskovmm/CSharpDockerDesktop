# IDD-0008.spec-interactive-terminal

## Intent

Provide an interactive command session inside an already running container without turning terminal input or session closure into container lifecycle commands.

## Related Specifications

IDD-0004, IDD-0006, IDD-0010, IDD-0011, IDD-0013.

## Behavior

- Opening a terminal creates an exec session in the selected running container, starts it attached with TTY, and exchanges input/output interactively.
- Support UTF-8, ANSI/VT output, keyboard input, selection, copy/paste, and terminal resizing.
- Propagate terminal dimensions through the Docker exec resize contract.
- Ctrl+C sends the terminal control byte to the TTY process; it must not invoke Stop on the container.
- Present session running/exit information when available from exec inspection.
- Closing the tab cleanly cancels/releases the client session and its connection. Closing a terminal must not stop the container.
- A missing shell/command produces a clear diagnostic without breaking the container details page.
- Exec requires an eligible running container. Paused/stopped or disappeared containers produce useful state/daemon errors.

## Product-Significant Architecture And Constraints

The public integration uses Docker exec create/start/resize/inspect and a duplex attached connection. A conventional logs response is not a terminal input transport. Session cancellation, EOF, and container termination must release client resources.

The source suggests a configurable command defaulting to /bin/sh. Exact command-selection UI and that default are not established requirements. The selected terminal surface and validated duplex integration remain active research in IDD-0013.

## Non-goals

- Guaranteeing a shell exists in every image.
- Starting a stopped container implicitly to open a terminal.
- Privileged exec controls in the MVP.
- Reusing Ctrl+C as a container stop action.
- Guaranteeing that closing the client session kills the exec process.

## Acceptance Criteria

- A supported shell session supports typing/output, copy/paste, resize, and Ctrl+C.
- Ctrl+C and closing the tab leave the container's lifecycle unchanged.
- Missing-command/distroless and ineligible-container cases display understandable diagnostics.
- Cancellation/EOF does not leave client streams or repeated background work active.

## Verification

Evidence covers attached duplex exchange, ANSI/UTF-8 rendering, resize, control-byte input, copy/paste, cancellation, abrupt EOF, command-not-found, stopped/paused containers, and container deletion. Real Engine evidence is required for the interactive behavior; a text-output mock alone cannot establish full terminal conformance.
